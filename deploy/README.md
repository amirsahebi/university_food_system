# راهنمای استقرار خودکار جوان‌فودز با انسیبل (Ansible Deployment)

این پوشه شامل اسکریپت‌های اتوماسیون استقرار (CI/CD / Orchestration) برای سرور عملیاتی جوان‌فودز است.

## ساختار فایل‌ها:
- `hosts.ini`: مشخصات اتصال SSH به سرور عملیاتی (`91.212.174.163`).
- `deploy.yml`: پلی‌بوک جامع برای نصب پیش‌نیازها، راه‌اندازی داکر، مایگریشن‌های جنگو، بیلد فرانت‌اند و راه‌اندازی مجدد Nginx.

## پیش‌نیاز اجرا روی سیستم محلی:
```bash
sudo apt install -y ansible
```

## دستور اجرا:
```bash
cd deploy
ansible-playbook -i hosts.ini deploy.yml
```
